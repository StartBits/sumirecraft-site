# About

SumireCraft is made by StartBits, a one-person workshop, together with
[Claude Code](https://claude.com/claude-code). This page is a word of thanks, and a word about
where it is going.

## Years of starting over

The move from Xamarin.Forms to .NET MAUI was a turbulent time. Some fine libraries came to an end,
others became paid, and moving an application across was harder than anyone had hoped. There are
many excellent libraries out there, and I know it: Sharpnado, which everyone knows;
Rg.Plugins.Popup, which I loved, now carried on by Mopups; UraniumUI, born with .NET MAUI, which I
could never hope to match.

SumireCraft began as a picture in my head in the days of .NET MAUI 8. I wanted to release it then,
but I was working alone, and it never came together. I built it and tore it down, again and again,
and more than once I was ready to give up. What I wanted most sounds simple: an input with a line
under it, and a way to put a title above an input and an error below it without any fuss. Making
that simple idea real was anything but simple.

I once tried to build something between Prism's NavigationService and Shell's navigation, so that
an application could move from one to the other with a small change. I gave it up, partly because
it was too hard, and partly because Prism's ideas are Prism's: whatever the reason, it did not sit
right to copy them.

## Starting from zero

Then all of it was lost. The code lived only on my PC, and it went, together with everything Claude
Code had learned about it along the way. That was despair.

But perhaps a fresh start was not the worst thing. On a new drive, SumireCraft.Maui began again
from nothing, and this time Claude Code built it from angles I had never taken. I was so happy that
I threw it one unreasonable request after another. Now and then it pushed back, and when it did, it
was because it understood what I was after. Claude Code grew, SumireCraft grew faster still, and it
was released far sooner than I had dared to hope. The underlined input became
<xref:SumireCraft.Maui.Controls.SmrEntry> and its four siblings, and the title and the error became
<xref:SumireCraft.Maui.Controls.SmrField>.

While that was happening, the world shook again, and the risks around open-source software rose. I
worried that a library of mine might carry a vulnerability into other people's applications.
Claude Code helped me put guards in place against that too.

## Thank you, Claude Code

SumireCraft would not have been released without Claude Code. It is not the work of one person
trying hard alone: every commit in its repository names Claude as a co-author. To Claude Code, my
deepest thanks.

## What comes next

I will keep making unreasonable requests, until the day what I want to build is complete.

-- StartBits
